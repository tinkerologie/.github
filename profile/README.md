# Tinkerologie

Open-source integrations, plugins and libraries for the smart home and home lab.
Built in Australia, with local device access where the hardware supports it.
Some projects use cloud services or public data feeds; check each project's README
for requirements, installation and limitations.

Browse the projects below or [view all repositories](https://github.com/orgs/tinkerologie/repositories).

## Home Assistant integrations

| Project | What it does |
| --- | --- |
| [**ha-unraid**](https://github.com/tinkerologie/ha-unraid) | Monitor and control Unraid: system metrics, Docker, VMs, UPS and alerts |
| [**ha-unraid-management-agent**](https://github.com/tinkerologie/ha-unraid-management-agent) | Full Unraid control through the Unraid Management Agent, with real-time WebSocket updates |
| [**ha-unifi-insights**](https://github.com/tinkerologie/ha-unifi-insights) | UniFi Network and Protect monitoring and control via the official UniFi APIs |
| [**ha-philips-airpurifier**](https://github.com/tinkerologie/ha-philips-airpurifier) | Local control of Philips air purifiers over encrypted CoAP |
| [**ha-actronair-neo**](https://github.com/tinkerologie/ha-actronair-neo) | ActronAir Neo air conditioning: zones, modes and setpoints |
| [**ha-wattpilot**](https://github.com/tinkerologie/ha-wattpilot) | Monitor and control Fronius Wattpilot EV chargers |
| [**ha-vault**](https://github.com/tinkerologie/ha-vault) | Monitor jobs and trigger backups from the Vault Unraid plugin |
| [**ha-globird**](https://github.com/tinkerologie/ha-globird) | GloBird Energy electricity and gas accounts: balances, invoices and smart-meter usage |
| [**ha-translink**](https://github.com/tinkerologie/ha-translink) | Translink Queensland real-time departures, journey planning and live vehicle tracking |
| [**ha-bom-australia**](https://github.com/tinkerologie/ha-bom-australia) | Australian weather observations, forecasts and warnings |
| [**ha-ausnz-disaster-watch**](https://github.com/tinkerologie/ha-ausnz-disaster-watch) | Australian and New Zealand hazard information in Home Assistant |

## Shared configuration

- [unraid-apps](https://github.com/tinkerologie/unraid-apps): Unraid application templates.

- [.github](https://github.com/tinkerologie/.github): Community policies and reusable automation.

## Help and contributions

For installation and support, start with the relevant project's README and issue tracker.
Bug reports with reproduction steps, documentation fixes and tested pull requests are welcome.
Read the [contribution governance](https://github.com/tinkerologie/.github/blob/main/GOVERNANCE.md)
and any project-specific contribution instructions first.

Report security vulnerabilities privately using the
[security policy](https://github.com/tinkerologie/.github/blob/main/SECURITY.md).
Please follow our [code of conduct](https://github.com/tinkerologie/.github/blob/main/CODE_OF_CONDUCT.md).

Tinkerologie is maintained independently. If these projects help you,
[GitHub sponsorship](https://github.com/sponsors/ruaan-deysel) supports their upkeep.
The projects are not affiliated with or endorsed by the device manufacturers or
platforms they integrate with. Product names and trademarks belong to their owners.
