# Getting Help

## Found a bug or have an idea?

Open an issue in the project's repository using the **Bug report** or
**Enhancement request** template. Search existing issues first; adding
details to an existing issue helps more than a duplicate.

Include the project version, your platform version (Home Assistant,
Homebridge, Unraid, Python or Node), and relevant logs with secrets removed.

## Security problems

Report them privately through the repository's **Security** tab. See the
[Security Policy](SECURITY.md).

## Contributing

Pull requests are welcome. Read the
[contribution governance](GOVERNANCE.md) and the repository's
`CONTRIBUTING.md` first.
